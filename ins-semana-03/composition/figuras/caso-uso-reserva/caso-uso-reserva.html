Reservar una canchacaso de uso
ObjetivoDejar una cancha reservada para una fecha y hora
Precondición: el administrador inició sesión y hay canchas registradas
1. Elige fecha y hora
2. El sistema muestra las canchas libres
3. Elige una cancha
4. Confirma la reserva
5. El sistema la registra y envía la confirmación
3a. La cancha ya fue reservada por otra persona: el sistema avisa y propone las canchas libres más cercanas en horario
Finaliza cuando: la reserva queda registrada y el administrador recibe la confirmación
Un caso de uso describe una interacción completa con el sistema
Actor, objetivo y precondición: de dónde se parte
El escenario principal: cinco pasos, todo sale bien
El escenario alternativo parte de uno de los pasos
