1 Aprovisionamiento
# count = 12 $ terraform apply Plan: 12 to add, 0 to destroy. matricula[0]: Creating... Apply complete! 12 added.
La herramienta lee el código y lo traduce en llamadas a la API del proveedor
2 Gestión de cambios
$ terraform plan ~ matricula[0] instance_type: m5.large -> m5.xlarge Plan: 12 to change.
Se reaplica el código para corregir la deriva; si el cambio es riesgoso, blue-green
3 Desmantelamiento
$ terraform destroy Plan: 0 to add, 12 to destroy. Destroy complete! 12 destroyed.
Los recursos se destruyen limpios; un stack efímero se borra al terminar
El mismo código crea, cambia y destruye: el ciclo de vida queda escrito
Toda la infraestructura pasa por tres fases
Aprovisionamiento: el código se traduce en recursos reales
Gestión de cambios: se reaplica para eliminar la deriva, con cambios pequeños
Desmantelamiento: se destruye todo cuando deja de hacer falta
Un solo código gobierna las tres fases
