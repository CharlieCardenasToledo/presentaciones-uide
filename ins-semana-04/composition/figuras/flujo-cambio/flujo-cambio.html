1Crear una rama corta
git switch -c reserva-tarifa
2Registrar el trabajo
git add .
git commit -m "Suma tarifa"
3Publicar la rama
git push -u origin reserva-tarifa
4Abrir un pull request
Acción en GitHub
5Revisar
Comentarios y aprobaciones en el pull request
6Integrar y limpiar
git pull
git branch -d reserva-tarifa
Un cambio pequeño viaja de la rama al trunk en seis pasos
La rama aísla el cambio sin afectar al resto del equipo
Cada commit guarda un avance pequeño con un mensaje claro
Se sube la rama al repositorio compartido
El pull request pide que otras personas revisen antes de integrar
La revisión detecta errores y comparte conocimiento
Se fusiona en main, se actualiza y se borra la rama
